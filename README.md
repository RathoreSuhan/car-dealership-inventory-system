# Car Dealership Inventory System

A full-stack Car Dealership Inventory System built as part of the Incubyte TDD Kata.

## Technology

Backend

- Java 21
- Spring Boot
- Spring Security
- PostgreSQL
- Spring Data JPA
- JUnit 5
- Mockito

Frontend

- React
- Tailwind CSS

## Development Approach

- Test Driven Development (TDD)
- SOLID Principles
- Clean Code
- Git-based incremental development
